# OpenFOAM Studio alpha candidate

AI-assisted OpenFOAM 13 workspace with a bounded cavity validation target. This candidate is built from one pinned commit after Stage 0–5, all unit suites, typechecks, and bundle checks pass. Checksums are included with the installers.

See the README, known limitations, privacy disclosure, and support/backup guidance. API provider calls can transmit case text/logs to the selected endpoint. A completed solver is not proof of engineering accuracy. Target artifacts: macOS ARM64, macOS Intel, Windows x64.

Unsigned alpha distribution remains a known limitation unless the release separately includes verified signing/notarization evidence. Clean-machine artifact startup/install/reinstall and credentialed-provider journey evidence must be recorded before broad announcement. This note describes candidate scope, not completion of external release gates.
