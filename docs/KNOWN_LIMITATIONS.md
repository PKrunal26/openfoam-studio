# Alpha scope and known limitations

The supported launch target is OpenFOAM 13 Foundation and the documented laminar incompressible cavity at Re=100. This is a validation target pending candidate evidence, not a claim that every provider or installer passed. Turbulence, multiphase, heat transfer, arbitrary geometry, CAD import, optimization, and sweeps remain experimental unless a versioned release explicitly reports their tests.

The Stage 4 Ghia comparison uses a 20×20×1 mesh, absolute normalized velocity tolerance 0.15, excludes near-wall reference points, and samples the cell-center line at normalized x=0.475. It does not establish ±5% error or general engineering accuracy. Solver exit, residual trends, mesh quality, finite-field checks, conservation, and applicable benchmark agreement represent different evidence. Engineers must review assumptions and perform mesh/time refinement and appropriate independent validation.

Provider/model access varies by account and region. API connection tests send a synthetic prompt and confirm a response only; they do not certify tool capabilities or CFD generation. The explicit CLI connection test sends a tiny prompt to verify a response from the selected model; read-only setup checks confirm only login status and can miss expired tokens. Custom model IDs remain allowed.

Model suggestions were checked against official catalogs on 7 October 2026: [Google models](https://ai.google.dev/gemini-api/docs/models), [Anthropic models](https://platform.claude.com/docs/en/models/overview), and [OpenAI GPT-5.2](https://developers.openai.com/api/docs/models/gpt-5.2). Gemini 3 Pro Preview is shut down and 2.5 access is restricted for fresh users. Gemini defaults use the catalog's fresh-project recommendation. Updated Anthropic suggestions are offered while the existing API default is retained pending app-specific evaluations. Codex `gpt-6.1-sol` is the default for unconfigured installs. Users can choose Codex CLI or Claude Code CLI in Settings; explicit provider/model choices are preserved. Neither the default nor a successful connection test establishes CFD performance. The model is documented in [official OpenAI model guidance](https://developers.openai.com/api/docs/models/gpt-6.1-sol), and login commands in the [official CLI reference](https://learn.chatgpt.com/docs/developer-commands?surface=cli). Account-specific access must pass the explicit connection test.

Candidate platforms are macOS ARM64, macOS Intel, and Windows x64. Signing, notarization, packaged startup, reinstall, and data-preservation smoke tests on clean machines remain release gates. Large VTK data and dense views can require substantial RAM/GPU resources; no large-case performance guarantee is made.
