# Raw Sources

Place immutable source documents here for wiki ingestion.

Rules:

- Add sources here, but do not edit them during ingest
- Prefer plain text or markdown when possible
- Name files clearly so summary pages can mirror them
- Treat repo tests and fixtures as separate first-class evidence even when they are not copied into `raw/`

Typical contents:

- copied documentation excerpts
- research notes
- benchmark descriptions
- architecture notes prepared for ingestion
- transcripts or design discussions
