# Bundled cavity reference visualization

This reference example pairs the dedicated cavity starter inputs with repository VTK fixtures at t=10. It opens the viewer without Docker or AI setup. The copied fixtures demonstrate visualization; they do not certify the paired inputs, solver convergence, or Ghia benchmark accuracy. No solver was run to create this bundled copy.

`reference.json` records source, field units, provenance, and exact asset hashes. Runtime project metadata must label this example as reference data and disable AI, solve, and conversion actions. Create the separate cavity starter to run your own simulation.
