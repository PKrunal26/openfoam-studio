# Bundled cavity starter

This dedicated, version-controlled starter is packaged independently of generated test fixtures and local user projects. It contains eight input dictionaries/fields and no solved output. It uses OpenFOAM 13 Foundation `incompressibleFluid`, laminar flow, a 0.1 m square domain, 1 m/s moving lid, viscosity 0.001 m²/s (Re=100), a 20×20×1 mesh, deltaT 0.005 s, and endTime 10 s. Inspect these assumptions before running. A shipped starter is not a pre-certified solved example; release benchmark evidence must identify its exact revision.
